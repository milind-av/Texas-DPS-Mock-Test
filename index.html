What this test covers

Each test draws 30 questions across every topic on the Texas Class C knowledge test, the same length and 70% passing score as the real one. New tests pick questions you haven't seen yet before repeating any.

Questions are written from the Texas Driver Handbook and the Texas Transportation Code. Laws change, so study the current handbook from Texas DPS too.
